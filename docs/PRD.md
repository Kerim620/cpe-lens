# CPE Lens 产品需求文档

## 1. 产品定位

CPE Lens 是一个只在本机运行的 Huawei HiLink CPE 管理面板，面向所有提供 HiLink API 的 Huawei/SoyeaLink 设备。它通过设备 API 获取状态并修改设置，重点解决原厂页面信号信息不完整、缺少历史趋势、功能分散的问题。设备型号、固件和可用能力由连接后的实际探测决定。

项目默认只监听 `127.0.0.1`，不连接云服务，不收集遥测。

## 2. 技术方案

- 后端：Python 3.11+、FastAPI、`huawei-lte-api`
- 前端：React、TypeScript、Vite、Tailwind CSS
- 数据库：SQLite
- 项目管理与启动：Python 标准 venv + pip；前端依赖由 npm 管理（仅开发前端时需要）
- 平台：先支持 macOS
- 设备：第一版管理一台 Huawei HiLink CPE；具体型号和功能以探测结果为准
- 语言：简体中文、英文
- 主题：跟随系统，也可手动切换
- 许可证：MIT；第三方依赖遵守各自许可证

计划提供统一命令：

```bash
python -m cpe_lens dev
python -m cpe_lens start
python -m pytest
```

## 3. 功能范围

### 连接与设备探测

- 输入管理地址、用户名和密码连接设备。
- 自动处理 Cookie、Session 和 CSRF Token。
- 读取型号、固件、Web UI 版本和设备信息。
- 启动或手动触发能力探测。
- 密码默认只保存在后端内存，不写入 SQLite 或日志；用户显式勾选浏览器“记住”时才写入 localStorage，并需提示风险。

每项能力显示以下状态之一：可用、实验性、当前不可用、无权限、不支持或探测失败。超时等临时错误不能直接判定为不支持。

### 总览

- 连接状态、运营商、SIM、LTE/5G NSA/SA 状态。
- 设备型号、固件、运行时间、WAN/LAN 地址。
- 实时上传和下载速度。
- 当前 Band、PCI、Cell ID 和核心信号指标。

### 信号与小区

- LTE/NR RSRP、RSRQ、RSSI、SINR。
- Band、EARFCN/NR-ARFCN、PCI、Cell ID。
- 设备可提供时显示频率、带宽、载波聚合、CQI、MCS、Tx Power 和 MIMO。
- 当前值、平均值、最大值、最小值和历史曲线。
- 单个字段缺失不影响其他数据展示。

### 流量与客户端

- 实时、本次连接、今日、本月和累计流量。
- 历史速度和流量曲线。
- 已连接客户端的名称、IP、MAC、连接方式和在线时间。
- 原始采样默认保存 30 天，之后按小时聚合并保留一年。

### 设备控制

设备支持时实现：

- 移动数据和漫游开关、重新拨号、重启设备。
- Wi-Fi、访客网络、SSID、密码和黑白名单。
- 网络模式和 APN 的查看、新增、修改、删除与设为默认。
- SMS 收发和删除、USSD 请求。
- LTE/NR Band Lock、Cell Lock 和恢复自动模式。
- DHCP、DNS、端口映射、DMZ、NAT、UPnP、防火墙等高级设置。

不实现恢复出厂设置、破解固件或绕过设备权限。

### 诊断

- 显示接口错误和能力探测结果。
- 导出诊断报告。
- 密码、Token、Cookie 和短信正文不得进入报告。
- IMEI、MAC、WAN IP 和手机号完整显示；仅登录密码、Cookie、Token、Session、Wi-Fi/APN 密码不暴露。

## 4. 写操作安全

关闭 Wi-Fi、修改 APN/网络模式、Band Lock、Cell Lock、重启和高级网络设置必须：

1. 先读取并展示当前值。
2. 说明修改影响，可能导致失联时明确警告。
3. 要求用户二次确认。
4. 写入后重新读取并验证结果。
5. 在能够恢复时提供恢复入口。

## 5. 页面结构

- 总览
- 信号与小区
- 流量
- 客户端
- Wi-Fi
- 移动网络与 APN
- SMS/USSD
- Band/Cell Lock
- 高级设置
- 诊断与应用设置

不支持的功能仍可显示入口，但必须说明原因。

## 6. 第一版完成标准

- 能稳定连接并识别 Huawei HiLink 设备，完成设备能力探测。
- 总览、信号、小区、流量和客户端页面可用。
- 保存和展示历史信号与速度数据。
- 支持中文、英文、浅色和深色主题。
- 设备断线、登录失效和单个接口失败不会导致整个页面不可用。
- 修改类功能根据实机探测结果逐项开放，统一执行能力检查、旧值展示、二次确认和回读验证；未验证功能标记为实验性。
