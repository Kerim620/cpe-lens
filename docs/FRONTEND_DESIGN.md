# 前端设计规范

本文描述 2026-11 重构后的前端。旧版的深色卡片布局、顶部工具栏和 12 项平铺导航不再适用。
设计的核心是**数据优先**：先让用户看清当前网络表现与历史变化，再提供受保护的控制入口。

## 1. 设计目标

- 总览、信号、流量、客户端是主任务；配置、诊断和设置是次级任务。
- 不把设备型号写死到界面；型号、固件、能力和字段均来自 API。
- 不为了视觉效果虚构数据、补零或平滑断点。
- 所有写操作仍必须经过能力检查、旧值展示、二次确认、令牌和回读验证。
- 所有用户可见文字支持中文/英文，所有颜色支持浅色/深色。

## 2. 技术栈

| 层 | 选择 |
| --- | --- |
| 框架 | React 19 + TypeScript strict + Vite 7 |
| 样式 | Tailwind CSS 4，`@tailwindcss/vite`，语义 CSS 变量 |
| 基础控件 | `components/ui/` 本地 shadcn/ui 风格源码，Radix Primitives |
| 图标 | `lucide-react` 静态命名导入；禁止 namespace 导入整套图标 |
| 图表 | `components/charts/`，基于 Tremor Raw 结构适配 Recharts 3 |
| 路由 | React Router 7，保留原有 12 个 URL，页面级懒加载 |
| 测试 | Vitest + Testing Library + jsdom |

Tailwind 4 的默认浏览器基线为 Safari 16.4+、Chrome 111+、Firefox 128+；本项目不额外支持更旧的浏览器。
运行时不加载 CDN、远程字体、远程图标或运行时组件。系统字体栈：
`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。

## 3. 视觉语言

- 中性背景、低装饰、细边框、低阴影；信息层级通过字号、字重和留白建立。
- 主色为青绿色，下载/上传、LTE/NR 使用固定数据色，不随主题改变语义。
- 指标数字使用 tabular numerals；单位比数值小一号，始终与数值同行。
- 卡片圆角 8–12px，控件 6–8px；不使用大面积渐变或玻璃拟态作为主视觉。
- 图表网格线只保留水平细线；坐标轴不画边框。

语义令牌定义在 `src/index.css`：

| 令牌 | 用途 |
| --- | --- |
| `background` / `foreground` | 页面底色和主文字 |
| `card` / `card-foreground` | 卡片 |
| `muted` / `muted-foreground` | 次级背景和说明文字 |
| `border` / `input` / `ring` | 边框、输入、焦点 |
| `primary` / `secondary` / `accent` | 主操作、次级操作、选中 |
| `success` / `warning` / `destructive` / `info` | 状态 |
| `chart-download` / `chart-upload` | 下行/上行 |
| `chart-lte` / `chart-nr` | LTE/NR |
| `chart-grid` / `chart-neutral` | 网格和中性序列 |

浅色和深色共享同一组令牌；组件不得写死 `gray-*` 或十六进制颜色。Tailwind 类名使用静态映射。

## 4. 应用外壳

### 侧栏

- 桌面固定 14rem（224px）；移动端使用左侧抽屉。
- 品牌区：CPE Lens + “Huawei HiLink 管理”。
- 主导航（始终可见）：总览、信号与小区、流量、客户端。
- “设备管理”分组：设备与能力、Wi-Fi、移动网络与 APN、Band/Cell Lock、短信与 USSD、高级设置。分组始终展示，不再折叠。
- “系统设置”分组：诊断、应用设置。
- 桌面侧栏可整体收起为 3rem（48px）图标栏；收起状态保存在 localStorage；切换按钮位于侧栏最下方，支持 Cmd/Ctrl+B。
- 底部：仅保留“收起侧边栏/展开侧边栏”按钮；设备状态卡和“只在本机运行”不放在侧栏。

### 顶栏

- 高 56px，粘性定位，背景带轻微模糊。
- 左侧：侧栏切换按钮（移动端打开抽屉）、当前页面、型号/制式。
- 右侧：连接状态、最后更新时间、全局刷新、全屏、主题、语言。子页面不再各自提供“刷新数据”按钮。
- 主题选项：跟随系统、浅色、深色；语言：中文、English。
- 刷新同时触发设备快照和实时看板刷新；刷新中旋转图标并禁用按钮。

主内容不设居中最大宽度；桌面使用标准 24px 页面内边距，平板 20px，手机 16px。侧栏与主内容之间是正常页面间距，不做特殊贴边或额外空白。页面底部显示
“CPE Lens · 仅本机运行 · 无遥测”。

## 5. 页面结构

实时数据通过 SSE `/api/events` 推送，全部区块严格按应用设置中的采样间隔刷新；不采用 WebRTC，因为设备数据源是 HTTP/XML。全屏通过浏览器 Fullscreen API 进入监测布局，隐藏侧栏、顶栏、页脚和页头，仅保留 KPI 与多张趋势图。5G 模式仅在设备 `net/net-mode-list` 明确报告时出现，不猜测固件代码。

### 全屏监测

- 顶栏全屏按钮请求原生 Fullscreen API；ESC 退出同步状态。
- 全屏中隐藏侧栏、顶栏、页脚、页头、信息卡、客户端/小区表和外部链接。
- 总览显示紧凑 KPI、速率图、数据量图、RSRP/SINR/RSRQ/RSSI 趋势图；其他页面隐藏外壳但保留内容。
- 原生全屏被拒绝时进入同布局的聚焦模式，并保留“退出全屏”按钮。


| 页面 | 内容重点 |
| --- | --- |
| 总览 | 4 个 KPI、网络状态/流量汇总/客户端摘要、速率面积图、信号趋势、核心信号、小区摘要、能力摘要；无设备信息卡 |
| 信号与小区 | LTE/NR KPI、RSRP/RSRQ/SINR 切换、历史趋势、范围统计、无线详情、小区表 |
| 流量 | 下载/上传/今日/本月 KPI、速率面积图、数据量柱状图、范围统计 |
| 客户端 | 总数/Wi-Fi/有线 KPI、搜索、客户端表 |
| 设备与能力 | 身份、会话、能力探测表（筛选/搜索/滚动）、断开连接 |
| Wi-Fi | 当前设置、SSID/密码/隐藏表单、能力限制说明 |
| 移动网络与 APN | 移动数据/漫游/重新拨号、APN 表/卡片、新增/编辑表单 |
| 短信与 USSD | 短信列表、发送、标记已读/删除、USSD 状态与请求 |
| Band/Cell Lock | 网络模式、LTE 频段、Cell Lock 只读说明 |
| 高级设置 | DHCP/DNS、UPnP、DMZ、防火墙；端口映射/NAT 只读说明 |
| 诊断 | 设备/运行参数、能力表、实时错误、操作记录、导出、重启 |
| 应用设置 | 采样、心跳、区块超时、历史保留；只展示用户需要的字段 |

总览连接前只显示连接入口；连接后不显示配置表单、重启或锁频操作。
连接页提供可选的“记住用户名和密码”；默认关闭，开启后明文保存在浏览器 localStorage，并显示风险提示。

## 6. 图表规则

- 速率：面积图，下载/上传双序列，单位 bit/s。
- 数据量：柱状图，按历史采样区间显示字节数。
- 信号：折线图，按 RSRP/RSRQ/SINR 切换；LTE 和 NR 固定颜色；dBm/dB 不与其他单位混轴。
- 时间范围：15 分钟、1 小时、6 小时、24 小时、7 天；15 分钟范围显示秒，避免相邻采样标签重复。
- 缺失值保留 `null`，`connectNulls=false`；全空序列显示空状态，不绘制 0。
- 图例在图表下方；悬停显示时间、序列和值；无数据时显示 `history.empty`。
- 图表带 `role="img"` 和可读的 `aria-label`；空状态也有同一语义。
- 渐变 ID 使用 `useId` 生成，避免同页多图冲突。

## 7. 状态与错误

每个资源必须处理：

- 首次加载：Skeleton，不使用假数据。
- 刷新：保留旧内容，按钮显示“正在刷新”。
- 断线：显示连接入口；实时数据不补零。
- 区块错误：保留上次成功数据并显示错误；若数据过期，显示“正在显示某时间的最后有效数据”。
- 空记录：明确空状态。
- 不支持/无权限/探测失败：显示能力状态和原因，写入口仍由后端拒绝。

`SectionError` 同时处理错误和 stale；`ErrorBanner` 用于请求级错误；`DataNotice` 用于能力/安全说明。

## 8. 写操作对话框

`OperationDialog` 必须完整保留：

- 能力 ID 与风险等级；
- 旧值和新值双栏；
- 后端 warnings；
- 显式确认复选框；
- 取消、确认执行、执行中禁用；
- 结果状态、回读验证、设备输出、错误详情；
- 焦点进入对话框、Escape 关闭（执行中除外）、移动端可滚动。

开关和按钮不得直接绑定设备写接口；只能通过 `useOperation.start` 生成计划。

## 9. 响应式

- `lg`（1024px）起固定侧栏；以下使用抽屉。
- `sm` 起顶栏显示连接状态；手机只保留状态点、刷新、主题、语言。
- KPI 手机 2 列，桌面 4 列。
- 图表在窄屏保持全宽，坐标标签减少；15 分钟范围使用秒。
- 宽表（客户端、小区、能力）设置最小宽度并允许容器内横向滚动；APN 在手机使用卡片，桌面使用表格。
- 操作对话框最大宽度 42rem，手机宽度 `calc(100% - 2rem)`，最大高度 92vh。

## 10. 可访问性

- 所有交互控件使用可聚焦的原生按钮/输入或 Radix 控件。
- 图标按钮必须有 `aria-label`。
- 表单控件必须有 Label；Radix Select 触发器补充 `aria-label`。
- 对话框使用 DialogTitle/Description，焦点陷阱由 Radix 提供。
- 颜色不是唯一状态信号：状态徽章同时有图标和文字。
- 尊重 `prefers-reduced-motion`：CSS 关闭动画；图表关闭 Recharts 动画。
- 键盘可访问导航、表单、表格、对话框和主题/语言菜单。

## 11. 性能与资源

- 12 个页面通过 `React.lazy` 按路由加载；`AppShell` 保持挂载，避免导航重连。
- Recharts、Radix 分为独立 vendor chunk；图表只在数据页需要时加载。
- 生产构建参考（2026-11）：

| 资源 | 未压缩 | gzip |
| --- | --- | --- |
| 入口 JS | 约 378 KB | 约 119 KB |
| 图表 vendor | 约 409 KB | 约 117 KB |
| Radix vendor | 约 137 KB | 约 45 KB |
| CSS | 约 36 KB | — |

- 不引入第二个图表引擎；不引入整套图标包；不运行时下载组件。
- 页面首次加载包含总览所需图表，因此总览会加载图表 vendor；次级页面按需加载。

## 12. 验证清单

```bash
cd frontend
npm run typecheck
npm run test
npm run build
```

人工检查：

- 12 个路由的中英文页面标题和主要文案；
- 浅色/深色、390px/桌面视口、无横向溢出；
- 侧栏整体收起/展开、移动端抽屉、当前路由高亮；
- 主题/语言切换持久化；
- 断线后连接入口和恢复；
- 图表空数据、缺失断点、时间范围切换；
- 计划对话框取消、确认、结果/回读状态；
- 浏览器 Network 不出现外部域名；
- 键盘 Tab、Escape 和焦点可见。
