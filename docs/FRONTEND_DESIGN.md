# 前端设计规范

## 1. 设计方向

界面采用简洁、专业的 Huawei HiLink CPE 网络监控面板风格。不要做成高饱和霓虹色的“黑客面板”。默认跟随系统主题，并允许手动切换浅色、深色和系统模式。

## 2. 整体布局

- 左侧导航：总览、信号、小区、流量、客户端、设置等页面。
- 顶部状态栏：设备连接状态、网络制式、最后刷新时间、语言和主题。
- 主区域：页面标题、异常或能力提示、页面内容。
- 桌面端优先，同时保证平板和窄窗口可以使用。

总览首屏优先展示：设备在线状态、运营商及网络制式、实时速度、核心信号、Band/PCI/Cell ID。

## 3. 视觉基础

### 色彩

- 背景：浅色 `#F5F7FA`，深色 `#0B0F14`。
- 卡片：浅色 `#FFFFFF`，深色 `#121820`。
- 主色：浅色 `#176B87`，深色 `#43B6D4`。
- 成功/良好使用绿色，警告/实验性使用琥珀色，错误/危险使用红色，不支持使用灰色。

不能只依靠颜色表示状态，必须同时显示文字或图标。

### 尺寸

- 使用 4px 间距体系，常用间距为 8、12、16、24、32px。
- 卡片圆角 10px，按钮和输入框圆角 8px，默认控件高度 40px。
- 正文 14–16px，核心指标 24–32px。
- 实时数字使用等宽或 tabular 数字，避免刷新时左右跳动。

## 4. 核心组件

### 指标卡

显示名称、数值、单位、质量等级、更新时间和可选趋势。数据缺失时说明“不支持”“当前不可用”或“读取失败”，不能用 `0` 代替缺失值。

### 图表

- 支持 15 分钟、1 小时、6 小时、24 小时和 7 天范围。
- LTE 与 NR 曲线颜色固定且带图例。
- 鼠标悬停显示准确时间和数值。
- 提供当前、平均、最大和最小值。

### 表格

用于客户端、短信、APN 和操作记录。支持必要的搜索、筛选和响应式滚动。敏感信息默认遮挡。

### 能力提示

- 可用：绿色勾选。
- 实验性：琥珀色标识并说明风险。
- 当前不可用：说明所需条件。
- 无权限：锁形标识并说明限制。
- 不支持：灰色标识并说明设备未提供接口。
- 探测失败：提供重新探测按钮。

## 5. 页面状态

每个页面或模块都要处理首次加载、正在刷新、旧数据/设备离线、无数据、不支持、无权限、读取失败和正常显示。

刷新时保留上一次数据并标记时间，不要让整个页面反复闪烁。

## 6. 危险操作

- 高风险按钮使用红色，并写清操作对象，例如“重启设备”。
- 确认窗口展示旧值、新值、可能影响和恢复方法。
- 关闭 Wi-Fi、修改网络和锁频时明确提示可能与设备失联。
- 执行后显示成功、失败或无法验证，不要只关闭对话框。

## 7. 多语言与可访问性

- 所有用户可见文本使用 i18n key，不在组件中硬编码中文或英文。
- 日期、流量、速度、频率和时间长度通过统一 formatter 显示。
- 所有功能可用键盘操作，焦点状态清晰。
- 图表提供文字摘要，状态变化不能只通过颜色表达。
- 遵循 `prefers-reduced-motion`，减少不必要动画。
